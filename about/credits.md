# Credits

Hippocampus meters work in credits. The rates can change, so this page names what is charged, not the numbers: `start` and `balance` show the current rates and your balance.

| Action | Charged |
|---|---|
| `search` | Credits per call |
| `ingest` (adding a document) | Credits per page; the estimated pages are set aside before the import starts and the charge is the real count |
| `start`, `find`, `open`, `read`, `balance`, `ingest_status` | Free |

| Fact | Detail |
|---|---|
| What a page is | A PDF page, a Word page or a PowerPoint slide; Markdown, text and Excel files count a fixed number of characters as a page |
| Whose balance | The workspace's, shared by its members |
| When credits run out | Search and adding documents are refused until the credits renew or more are added; finding, opening and reading still work |
| Free account | Includes MCP access and a monthly credit allowance |
| Who manages credits | The workspace owner, in Hippocampus |

Plans and prices: https://www.thalius.ai/pricing
