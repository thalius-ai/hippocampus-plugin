# Frequently asked

| Question | Answer |
|---|---|
| Do I need an account? | Yes, a Thalius account. A free account works: https://hippocampus.thalius.ai/register |
| Do I paste an API key? | No. Your AI app opens a browser window where you sign in to Hippocampus |
| The first call answers 401. Is that an error? | No. The client has no session yet; it reads the sign-in metadata and opens the sign-in page by itself |
| What can the assistant see? | Exactly the documents you may see in Hippocampus, nothing else |
| Can it change or delete my documents? | It can add documents when you ask (`ingest`), and only in folders where you can add documents yourself. You decide when you connect ("Let the agent add and update documents": ticked when Hippocampus verified the app, unticked for the device flow or an unverified app). It cannot delete or edit documents |
| Which files can I import? | PDF, scanned PDF, Word, PowerPoint, Excel, Markdown and text |
| Where are my documents stored? | Encrypted, in the EU (Finland) |
| Are my documents used to train AI? | No |
| Which AI apps work? | Any app that connects to a remote MCP server: Claude, ChatGPT, Codex, Cursor, VS Code, Gemini CLI, Antigravity, Kiro, Devin, Cline, Mistral Vibe, Perplexity and others |
| Why does an answer cite a page? | Every extract carries its document, section, pages and a link, so the answer can be checked |
| What costs credits? | Searching and adding documents. Finding, opening, reading and checking the balance are free. See [credits.md](credits.md) |
| How do I disconnect? | In Hippocampus, Connect to your AI → Connected apps, or remove the server in your AI app |
| Where do I get help? | support@thalius.ai |
